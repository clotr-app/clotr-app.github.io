Clotr for Windows and Android

Preview. This page says what I'm building toward for Windows and Android, not something you can install today. Each item is marked as built, being tested, or only designed so far, and nothing here is a promise of a date.

For what you can install right now, see the download page: the browser extension, for Chrome, Brave, Edge and Firefox on a computer.

Clotr for Windows

One program beside your other windows, built the same way as the browser extension: it reads what you choose to show it, checks it on your own computer, and says what it found.

  • Built, being tested: a copy check beside your AI desktop apps. Copy something private while ChatGPT, Claude or Copilot's own window is in front, and a card appears beside it, the same way the browser's warning does, before you paste it anywhere.

  • Built, being tested: Check my files. A Quick scan reads Downloads, Desktop and Documents, plus anything that's changed since your last Full scan; a Full scan reads every drive; Folders I choose reads only what you pick. Every scan skips the folders built for programs and a password manager's own vault, and Leave out lets you tell it to skip any folder yourself, any time. What it finds comes back grouped by what matters most, with words you can actually read, never a technical dump.

  • Being built: the typing check. Today Clotr for Windows only reads what you copy. The plan is to read the same message box as you type, the way a screen reader does, so a warning can show while you're still writing, not only after you've copied something. It reads only AI apps' message boxes, never a password box, and keeps nothing it reads.

  • Built, being tested: start with Windows. A setting to open quietly in the tray when your computer starts, off until you turn it on yourself.

  • What stays true at every step: everything happens on your own computer. There's no network code in it at all, nothing you copy, type or scan is ever sent anywhere, and a test fails the build the moment that ever stops being true.

Clotr for Android

A keyboard, in an early trial, with Clotr's own check built in behind it.

  • In an early trial. It's built on an existing, well-tested keyboard, so typing itself (layouts, autocorrect, languages) stays as solid as any other keyboard, with Clotr's check added behind it. Once you switch it on and pick it as your keyboard, it reads your message the same way the browser extension reads a chat box, only inside the AI apps it recognizes.

  • It skips password boxes, and outside the AI apps it recognizes it's just an ordinary keyboard, with Clotr's check turned off.

  • It asks for no internet permission at all, so there's no way for it to go online, whatever any library inside it might otherwise try to do.

  • Right now this is a private trial, measured and tested before it's offered to anyone to try themselves. Nothing typed in it leaves the phone.

One engine, wherever Clotr runs

Windows, Android and the browser extension all run the same checks for passwords, keys, card and ID numbers and the rest, written once and read the same way everywhere. Clotr has no AI inside any of them, just pattern checks you can read, and none of them ever talks to an AI service to do its job.
