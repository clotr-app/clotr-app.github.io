For developers

The engine that watches AI chats in the browser also runs where you write code. These tools are free, open source under AGPL-3.0-or-later, and they do their checking on your own machine.

Developer tools

  • The VS Code extension is also on Open VSX and flags credentials in open files; install with code --install-extension clotr-app.clotr or codium --install-extension clotr-app.clotr in VSCodium.

  • The JetBrains plugin source and README are at version 0.1.1. Its Marketplace page isn't live yet. The README explains its preview status and how to try it from a clone.

  • Clotr Guard on npm is a CLI with prompt hooks for Claude Code, Cursor, Gemini CLI, Codex CLI and Windsurf (and Cline on macOS and Linux), file-read hooks in Claude Code, Cursor, Gemini CLI and Windsurf, a Git pre-commit check and the clotr-mcp server; install with npm install -g clotr-guard, then run clotr-guard setup claude or clotr-guard setup git. The MCP server only checks when your assistant calls it; it doesn't watch prompts on its own.

  • The clotr-engine package on npm is Clotr's detection engine for scripts and tools; install with npm install clotr-engine.

The source

It's all at github.com/clotr-app/clotr, and each tool's README links the tests behind what it says. If Guard misses a key or warns about nothing, tell me.
