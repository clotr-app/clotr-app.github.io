Clotr for Windows

A desktop app that warns you before you paste something private into an AI app. Then it goes further and looks through your files for passwords, ID numbers and photos that give away a place, and finishes with a short list of what to fix first.

Clotr for Android

A phone keyboard with Clotr's check behind it, for the AI apps you type into, plus the same file check the Windows app has. It isn't on Google Play yet, and the next step is a small group of people using it for two weeks.

What anyone can check

  • There's no network code in Clotr, and a test fails the build if any is added. How the test works
  • Clotr spots private details with plain pattern matching that anyone can read, it never asks an AI service to do it, and there's no account either. Read the patterns
  • The build is reproducible: clone a release's tag, build it yourself, and its checksum matches the SHA256SUMS.txt published with it. Check a release
