What it looks for

Passwords and keys
API keys, tokens, webhook links, connection strings and seed phrases.
Card and bank numbers
Card numbers, Social Security and ITIN numbers, bank accounts, IBANs and medical record numbers.
Personal details
However you write them: in digits, number words, misspellings or a mix.
What scammers ask for
Texted sign-in codes, card security codes and remote-access codes.
Your own list
Names and details you add yourself, kept only as one-way fingerprints.
Text in files
Text, PDF, Word, Excel and PowerPoint files you attach.

It's on for 19 AI chat sites out of the box. Email and chat sites only when you switch them on.

What anyone can check

  • There's no network code in Clotr, and a test fails the build if any is added. How the test works
  • Clotr has absolutely NO AI. It spots private details with plain pattern matching that anyone can read, it doesn't talk to any AI service, and there's no account either. Read the patterns
  • The build is reproducible, so you can compare the store's zip with its SHA256SUMS yourself. Check a release
