The browser extension

The lightest way to try Clotr. Add it from your browser's own store, open an AI chat, and it starts reading the message box as you type.

Get the extension Get the extension Try it in this page first

On Edge? Get it from Edge Add-ons.

The extension runs on Chrome, Brave, Edge and Firefox on a computer. For a phone, see the Android preview.

Pick your browser's store

Brave uses the Chrome Web Store. Once it's added, pin Clotr to your toolbar. A welcome page opens with a practice box and asks which email and chat apps you use, since those stay off until you choose them.

What it looks for

Passwords and keys
API keys, tokens, webhook links, connection strings and seed phrases.
Card and bank numbers
Card numbers, Social Security and ITIN numbers, bank accounts, IBANs and medical record numbers.
Personal details
However you write them, in digits, number words, misspellings or a mix.
What scammers ask for
Texted sign-in codes, card security codes and remote-access codes.
Your own list
Names and details you add yourself, kept only as a scrambled code instead of the words.
Text in files
Text, PDF, Word, Excel and PowerPoint files you attach, and the place saved inside a photo.

It's on for 19 AI chat sites out of the box. Email and chat sites only when you switch them on. How it works

Or install it by hand

Firefox gets the newest version straight from its store. On Chrome, Brave or Edge you can load the newest release yourself before the store catches up.

  1. Download the latest clotr-<version>.zip from Releases and unzip it.
  2. Open chrome://extensions (brave://extensions or edge://extensions) and switch on Developer mode.
  3. Click Load unpacked and pick the folder you unzipped.
