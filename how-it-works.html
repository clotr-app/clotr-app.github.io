How it works, and your privacy

Clotr reads what you're about to send on your own device, and only there. Here's what happens, what it keeps, and how to check it yourself.

What happens when you type something private

  1. You type or paste as you always do: in an AI chat, an email, or a message.
  2. The engine reads it on your device. It looks for passwords, ID numbers, personal details and what scammers ask for, even when they're written out in words, like "five five five". Nothing is sent anywhere to do this.
  3. If it finds something, a note says what and lets you cover it. Cover it, or send it as is: it's your call, Clotr only stops a message if you've told it to.

One engine everywhere

Each part of Clotr runs the same engine, so a detail is caught the same way wherever you type: the extension and Clotr for Windows today, and Clotr for Android as it comes. Clotr has no AI inside it, just pattern checks you can read, and it never talks to an AI service to do its job.

How Clotr is built

Your privacy

  • Clotr doesn't send anything anywhere, no servers and no analytics, and a test checks that every single time the code changes.

  • It never saves what you typed, just what kind of thing it found, on which site, when, and what you did about it. You can look at all of it and delete it whenever you want.

  • It only runs where you say, out of the box only on AI chats, and on your email and chat apps only on the ones you pick, with your browser asking you first. In an email reply it checks what you type, and leaves the message you're answering alone, even when that message quotes your own details.

  • You can also switch on Everywhere I type. After your browser asks first, Clotr checks chat-style boxes on other websites too, but skips ordinary fields for names, addresses, payment details and sign-ins. It is off until you turn it on.

  • There's nothing to sign up for and nothing to sign in to.

Clotr for Windows

Clotr for Windows is in the Microsoft Store. It watches beside the ChatGPT, Claude and Copilot apps, once you've opened one, instead of in a browser tab. What it reads still never leaves your computer. See Clotr for Windows

  • It checks your clipboard once, the moment you copy something while one of those apps is in front, and a command the same way before it reaches the Run box or a terminal.

  • Check my files and Look back only read what you point them at: the folders you pick or Clotr suggests, or the one export file you choose, and nothing on their own unless you turn on the once-a-week check.

  • What it keeps sits in Clotr's own folder under your Windows profile and stays on this computer.

  • It has no network code built in, and a test reads the program Windows actually runs and fails the build if a network call ever shows up in it.

Check it yourself

Clotr's source is public under AGPL-3.0-or-later at github.com/clotr-app/clotr.

Each release has SHA256SUMS.txt. Every zip has signed build provenance and an SBOM. Verify with gh attestation verify <zip> -R clotr-app/clotr, or rebuild its tag with npm ci && npm run package and compare.

The extension has no network code. A rule test fails the build if it finds a network call.

The README permissions list says storage keeps settings and history, activeTab checks a page after a click, scripting starts checks, declarativeContent marks built-in AI chats, and alarms update counts and clear old history. Host access covers those chats. Optional site access is requested for added sites and Everywhere I type.

Test results

Version 1.4.0, tested 2026-10-16. I hid 6,200 personal details in 10,000 made-up messages, and this build caught every one, without a false alarm on the 3,800 that had nothing to catch. That's the set I used to find and fix what earlier versions missed, so it shows those cases are covered, not that Clotr catches everything. Typed the way people type on a phone, it caught 310 of 310. Real life is messier, so if it misses something or warns about nothing, tell me.

A score that gets worse fails the tests.
