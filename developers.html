For developers

The engine that watches AI chats in the browser also runs where you write code. These tools are free, open source under AGPL-3.0-or-later, and they do their checking on your own machine.

Developer tools

  • VS Code extension

    Flags credentials in open files. It's also on Open VSX for VSCodium. 

    code --install-extension clotr-app.clotr
codium --install-extension clotr-app.clotr

  • JetBrains plugin

    On the JetBrains Marketplace, and flags credentials in open files. Install it from Settings, Plugins. Its README explains how to try it from a clone.

  • Clotr Guard

    A CLI with prompt hooks for Claude Code, Cursor, Gemini CLI, Codex CLI and Windsurf (and Cline on macOS and Linux), file-read hooks in Claude Code, Cursor, Gemini CLI and Windsurf, shell-command and MCP tool-call checks in Claude Code and Cursor, a Git pre-commit check and the clotr-mcp server. 

    npm install -g clotr-guard
clotr-guard setup claude
clotr-guard setup git

    The MCP server only checks when your assistant calls it; it doesn't watch prompts on its own.

  • clotr-engine

    Clotr's detection engine for scripts and tools.

    npm install clotr-engine

The source

It's all at github.com/clotr-app/clotr, and each tool's README links the tests behind what it says. If Guard misses a key or warns about nothing, tell me. If your team uses it at work, add your team to the list.
